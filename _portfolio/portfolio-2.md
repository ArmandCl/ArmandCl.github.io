During my internship at Atempo, I worked as a QA Automation & DevOps Engineer within the R&D team. The main objective was to design and implement an automated non-regression testing infrastructure for Atempo's SaaS and hardware backup solution, Continuity.<br/><br/>I developed comprehensive test suites using Robot Framework and Python to secure product releases. To fully integrate test execution into the continuous integration workflow, I engineered Jenkins pipelines (Groovy) and automated virtual machine provisioning and snapshot management via VMware vSphere / vCenter. Additionally, I built a Python log-processing tool to parse and filter JSON diagnostic reports ('checkstates') sent by production appliances deployed at customer sites, making it easier to detect hardware and software anomalies. I also refactored deployment scripts using regular expressions to achieve fully automated, unattended installations.<br/><br/>Working in an Agile/Scrum environment with bi-weekly sprints, daily stand-ups, Jira, and Confluence gave me firsthand experience with industrial-grade QA processes and DevOps infrastructure. This project greatly strengthened my skills in Python automation, CI/CD pipelines, virtualization, and testing methodology in a production environment.<br/><br/>
